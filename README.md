# Aquarela — Under Construction

Landing page temporária da Aquarela Design, com tema dark, cards de vídeo, faixas animadas, scroll suave com Lenis e footer interativo.

## Tecnologias

- HTML, CSS e JavaScript
- WebGL para efeitos visuais da headline e do footer
- Lenis para suavização do scroll
- GitHub Pages para hospedagem

## Desenvolvimento local

Abra `index.html` em um servidor HTTP local para visualizar o projeto.

## Deploy

O deploy é publicado automaticamente no GitHub Pages a cada push para a branch `main`.
